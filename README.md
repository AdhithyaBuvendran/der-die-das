# Der Die Das Quiz

A browser quiz for learning German nouns with their articles (der, die, das, plural die), based on the vocabulary in the booklet *Deutsch lernen!* (Der Sächsische Ausländerbeauftragte).

## Modes
- **Artikel**: pick the correct article for a noun
- **Deutsch → English** and **English → Deutsch**: translate in both directions
- **Word list**: search all words and see the gender rule for each

Every answer shows the reason a noun has its gender, including exceptions.

## Run
Open `index.html` in any browser. No install or build step needed.
